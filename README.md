# CJ → eBay Dashboard

واجهة عامة لعرض فرص المنتجات وتشغيل مسار البحث والمراجعة الموحد في n8n.

## الأمان

- لا تنشر منتجات على eBay.
- لا تنشئ طلبات CJ.
- لا تنفذ مدفوعات.
- قرارات المراجعة تبقى منفصلة عن النشر.

## الربط

يحدد `config.js` عنوان خادم Dashboard API العام. هذا الخادم المحدود هو الوسيط بين GitHub Pages وn8n المحلي، ولا يكشف واجهة n8n نفسها.
